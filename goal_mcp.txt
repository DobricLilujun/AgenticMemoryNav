# MCP 无限画布系统目标文档


实现一个 MCP 无限画布系统：由 fake robot 作为 MCP Client，通过 MCP 调用全部 basic action（包括前进、后退、左右转、停止、抬头和低头），服务端根据动作更新机器人的二维位置与朝向，并自动记录移动轨迹；
同时支持通过 MCP 添加、更新和删除点状或线状障碍物，并保存其位置、尺寸、标签和置信度。系统使用不绑定具体物理含义的抽象单位长度，提供 `get_canvas` 返回当前完整画布状态，并通过 WebSocket 实时推送机器人、轨迹和障碍物变化；
最后通过 fake robot 的标准动作序列和障碍物场景进行端到端评估，验证 MCP 工具、状态更新、画布结果和实时事件是否正确。


## 1. 目标

实现一个 MCP Server，提供实时更新的二维机器人画布。

系统需要支持：

- Fake robot 作为 MCP Client 调用工具。
- 通过 MCP 执行机器人动作。
- 更新机器人的二维位置和朝向。
- 自动记录机器人运动轨迹。
- 通过 MCP 记录障碍物及其尺寸,可以估计。
- 返回当前二维画布状态。
- 暴露接口实时推送实时画布更新。
- 使用预定义动作序列自动评估正确性。

系统不指定实际物理单位。位置、移动距离、障碍物尺寸和画布坐标统一使用抽象的**单位长度**。

例如：

```text
move_step = 0.25 unit
obstacle radius = 0.20 unit
wall width = 0.10 unit
```

这些数值只用于相对几何关系和画布显示，不代表米、厘米或其他具体物理单位。

## 2. 系统结构

```text
Fake Robot / Evaluation Client
            │
            │ MCP tool calls
            ▼
        MCP Server
            │
            ├── Robot State
            ├── Trajectory
            ├── Obstacles
            ├── Event History
            └── Canvas State
                    │
                    ├── MCP get_canvas
                    └── WebSocket realtime updates
```

Fake robot 必须通过 MCP 调用服务，不能直接访问 MCP Server 的内部状态。

## 3. 坐标约定

使用二维抽象坐标系：

```text
x、y：单位长度
theta：角度
theta = 0：朝向正 x 方向
逆时针为正
```

初始状态：

```json
{
  "x": 0.0,
  "y": 0.0,
  "theta": 0.0
}
```

默认动作参数：

```json
{
  "move_step": 0.25,
  "small_turn_degrees": 15.0,
  "big_turn_degrees": 90.0
}
```

`move_step` 表示一次移动的单位长度，不指定物理单位。

## 5. 动作状态转移

每次移动必须：

- 收到指令以及成功失败的结果（有可能遇到障碍物，执行失败）。
- 画轨迹线段，成功失败都画，成功画黑色，失败画红色。
- 更新机器人当前位置，用一个显眼的比如说绿色标记指出。
- 每一次指令里还包含视觉障碍感知，然后去估计障碍物的位置。可以使线段，也可以是估计的形状等。
- 触发实时画布更新。
- 过去历史的轨迹线段变成虚线。

旋转动作：

- 更新机器人朝向。
- 不改变二维位置。
- 不生成移动轨迹。
- 生成动作事件。
- 更新画布中的机器人方向。


## 6. MCP 工具

### `create_robot`

```json
{
  "robot_id": "fake_robot_01",
  "start_pose": {
    "x": 0.0,
    "y": 0.0,
    "theta": 0.0
  }
}
```

### `execute_action`

支持 action name：

```json
{
  "robot_id": "fake_robot_01",
  "action": "move_forward"
}
```

支持 action ID：

```json
{
  "robot_id": "fake_robot_01",
  "action_id": 2
}
```

返回：

```json
{
  "robot_id": "fake_robot_01",
  "action": "move_forward",
  "action_id": 2,
  "pose_before": {
    "x": 0.0,
    "y": 0.0,
    "theta": 0.0
  },
  "pose_after": {
    "x": 0.25,
    "y": 0.0,
    "theta": 0.0
  },
  "trajectory_added": true,
  "canvas_version": 1
}
```

### `add_obstacle`

支持点和线。

点障碍物：

```json
{
  "robot_id": "fake_robot_01",
  "obstacle": {
    "obstacle_id": "obs_001",
    "type": "point",
    "position": {
      "x": 2.0,
      "y": 1.5
    },
    "size": {
      "radius": 0.2
    },
    "label": "box",
    "confidence": 0.95
  }
}
```

线障碍物：

```json
{
  "robot_id": "fake_robot_01",
  "obstacle": {
    "obstacle_id": "wall_001",
    "type": "line",
    "geometry": {
      "start": [1.0, 2.0],
      "end": [4.0, 2.0]
    },
    "size": {
      "width": 0.1
    },
    "label": "wall",
    "confidence": 1.0
  }
}
```

障碍物尺寸统一使用单位长度：

```text
radius = 0.2 unit
width = 0.1 unit
```

不得在接口、注释或文档中假定这些数值是米、厘米或其他实际单位。

障碍物支持字段：

```text
obstacle_id
type
position 或 geometry
size
label
confidence
source
timestamp
properties
```

### `update_obstacle`

```json
{
  "obstacle_id": "obs_001",
  "patch": {
    "position": {
      "x": 2.1,
      "y": 1.6
    },
    "size": {
      "radius": 0.25
    },
    "confidence": 0.97
  }
}
```

### `remove_obstacle`

```json
{
  "obstacle_id": "obs_001"
}
```

### `get_canvas`

返回当前完整二维画布：

```json
{
  "canvas_id": "main",
  "frame": "world",
  "coordinate_unit": "unit_length",
  "version": 7,
  "robots": [],
  "trajectory": [],
  "obstacles": [],
  "events": []
}
```

`coordinate_unit` 只能表达抽象单位，例如：

```text
unit_length
```

它不能写成：

```text
meter
centimeter
millimeter
```

### `reset_simulation`

```json
{
  "robot_id": "fake_robot_01",
  "clear_events": false
}
```

重置机器人、轨迹和障碍物状态。

## 7. 画布内容

画布必须支持：

### 机器人

```json
{
  "robot_id": "fake_robot_01",
  "position": [0.25, 0.0],
  "theta": 0.0
}
```

### 轨迹

```json
{
  "segment_id": "seg_001",
  "start": [0.0, 0.0],
  "end": [0.25, 0.0],
  "action": "move_forward"
}
```

### 点障碍物

```json
{
  "obstacle_id": "obs_001",
  "type": "point",
  "position": [2.0, 1.5],
  "radius": 0.2
}
```

### 线障碍物

```json
{
  "obstacle_id": "wall_001",
  "type": "line",
  "start": [1.0, 2.0],
  "end": [4.0, 2.0],
  "width": 0.1
}
```

前端必须按相同比例显示两个坐标轴。画布可以缩放和平移，但不能改变对象之间的相对几何关系。

## 8. Fake Robot 评估

Fake robot 是独立的 MCP Client，所有操作必须通过 MCP 工具完成。

```text
Fake Robot
  → call create_robot
  → call execute_action
  → call add_obstacle
  → call get_canvas
  → 校验返回结果
```

Fake robot 不允许直接读取：

```python
server.robot_state
server.canvas_state
server.database
```



## 9. 标准评估场景

### 场景一：连续前进

初始：

```text
position = (0, 0)
theta = 0
```

执行：

```text
move_forward
move_forward
move_forward
```

期望：

```text
position = (0.75, 0)
theta = 0
trajectory_count = 3
```

这里的 `0.75` 表示 `0.75` 个单位长度。

### 场景二：旋转后前进

执行：

```text
turn_left_big
move_forward
```

期望：

```text
theta = 90
position = (0, 0.25)
trajectory_count = 1
```

### 场景三：前进后退

执行：

```text
move_forward
move_backward
```

期望：

```text
position = (0, 0)
trajectory_count = 2
```

虽然机器人回到初始位置，但两条轨迹必须保留。

### 场景四：全部动作

依次调用：

```text
turn_left
turn_right
move_forward
stop
look_up
look_down
turn_left_big
turn_right_big
move_backward
```

验证：

- 所有动作均能调用。
- action name 和 action ID 映射正确。
- 移动动作生成轨迹。
- 旋转动作只改变朝向。
- `stop`、`look_up`、`look_down` 不改变二维位置。
- 每个动作都有事件记录。

### 场景五：障碍物

通过 MCP 调用：

```text
add_obstacle(point)
add_obstacle(line)
```

验证：

- 障碍物位置正确。
- 线段起点和终点正确。
- 障碍物尺寸正确。
- 标签正确。
- 置信度正确。
- 障碍物出现在 `get_canvas` 返回结果中。
- 障碍物事件被实时推送。

## 10. 实时更新

提供 WebSocket：

```text
/ws/canvas/main
```

事件类型：

```text
robot_updated
trajectory_added
obstacle_added
obstacle_updated
obstacle_removed
simulation_reset
```

示例：

```json
{
  "event": "trajectory_added",
  "canvas_version": 3,
  "data": {
    "robot_id": "fake_robot_01",
    "start": [0.0, 0.0],
    "end": [0.25, 0.0],
    "action": "move_forward"
  }
}
```

前端收到事件后必须立即更新二维画布。

## 11. 单位相关验收标准

必须满足：

```text
1. 所有坐标都使用抽象数值。
2. 所有移动距离都使用单位长度。
3. 所有障碍物尺寸都使用单位长度。
4. 不出现 meter、cm、mm 等单位假设。
5. 坐标比例保持一致。
6. 前端缩放不改变对象之间的相对位置。
7. MCP 返回中可以标记 coordinate_unit = unit_length。
```
